# Unseen — downloads

Страница скачивания Unseen для Windows, Android и Android TV.
Статический сайт: HTML, CSS и локальные файлы оформления.

Публикация GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).
Файлы приложений размещены в GitHub Releases. На странице ссылки на выпуск
`downloads-2026-11-01`: Windows 3.6.7, Android 0.84, TV 0.1.3.

Android TV — совсем ранняя версия, сейчас ориентированная на YouTube.
Приложения находятся в бета-тестировании. Работа зависит от сети.

Связь с разработчиком: https://www.instagram.com/unseen.connect/

Основной адрес сайта: https://unseen-app.github.io/
Файлы приложений продолжают скачиваться из существующего выпуска GitHub Releases.

Обновлённый дизайн: цифровой город на всём фоне первого блока, персонаж Unseen,
крупные заголовки Golos Text, плавная анимация и адаптация для телефона.
Лицензия Golos Text: `Golos-OFL.txt`. Изображение интерфейса Android — пример.

## Аналитика

Umami Cloud Hobby, европейский регион. Website ID: `444cec39-32c9-467d-bd17-d0946e998798`.
Просмотр статистики — через аккаунт владельца в https://cloud.umami.is/ .
Счётчик работает только на `unseen-app.github.io`; якоря страницы не разделяются на отдельные URL.

События: `download_windows`, `download_android`, `download_tv`, `contact_instagram`, `support_project`.
События скачивания и поддержки фиксируют нажатия на ссылки. Они не подтверждают установку приложения или завершение платежа.
Платный API и публичный доступ к статистике не включены.
