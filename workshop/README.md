# Мастерская приватности Unseen · бета 0.3

Страница `/workshop/`. Вход доступен из навигации сайта и отдельного блока под главным экраном. Настройки бота не меняются.

Статический HTML, CSS и JavaScript без зависимостей, аналитики, запросов к API и хранения изображений. CSP запрещает исходящие соединения. Файлы JPEG, PNG и WebP декодируются в браузере и обрабатываются через Canvas. Поддерживаются непрозрачные маски, пикселизация, перемещение и изменение размера областей, отмена, сравнение, квадратный кадр, свободная обрезка и повороты на 90°. Маски остаются в координатах исходного растра и сохраняются при обрезке и поворотах.

Повторяющийся диагональный водяной знак содержит пользовательскую подпись и необязательную дату с регулируемой прозрачностью. Он наносится на итоговый растр. Есть уменьшение по длинной стороне с сохранением пропорций, собственный размер и качество JPEG 40–100%. Изображения не увеличиваются сверх рабочего размера. После сохранения отображаются размеры и вес файла.

Кнопка «Выбрать кадр» входит в режим обрезки, а «Обрезать» применяет выбранный фрагмент. Выбранный кадр также применяется при сохранении или переходе к «Закрыть»/«Пиксели». При пустом выделении сохранение экспортирует прежний кадр. «Отмена», Escape, отмена последнего действия и сброс в режиме обрезки отменяют только незавершённый выбор. Применённую обрезку можно отменить обычной отменой действия. Разрыв сенсорного жеста не блокирует редактор.

Экспорт PNG/JPEG повторно кодирует растр без исходных EXIF и текстовых метаданных. Для чувствительного текста следует использовать непрозрачную маску. Пикселизация — визуальный эффект, который может оставлять содержание узнаваемым.

Лимит входного файла — 35 МиБ. Большие изображения уменьшаются до 4096 пикселей по длинной стороне и 6 Мп с уведомлением. Фотографии остаются в памяти документа. Для загрузки приложения нужен доступ к GitHub Pages. Работа в Telegram открывается обычной ссылкой; меню Main Mini App можно подключить после проверки.

Проверка из корня проекта: `python tools/check_privacy_workshop.py` (установленные Python Playwright, Pillow и Chrome). Проверяется экспорт, отсутствие внешних запросов, обработка без сети, сохранение масок при всех поворотах и обрезке, водяной знак, сжатие и сенсорное управление. Результаты и снимки находятся в `output/workshop-check/`.
