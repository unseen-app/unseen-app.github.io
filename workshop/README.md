# Мастерская приватности Unseen · тест 0.1

Изолированная тестовая страница `/workshop/`. Главная страница и настройки бота не меняются.

Статический HTML, CSS и JavaScript без зависимостей, аналитики, запросов к API и хранения изображений. CSP запрещает исходящие соединения. Файлы JPEG, PNG и WebP декодируются в браузере и обрабатываются через Canvas. Поддерживаются непрозрачные маски, пикселизация, перемещение и изменение размера областей, отмена, сравнение и квадратный кадр по центру.

Экспорт PNG/JPEG повторно кодирует растр без исходных EXIF и текстовых метаданных. Для чувствительного текста следует использовать непрозрачную маску. Пикселизация — визуальный эффект, который может оставлять содержание узнаваемым.

Лимит входного файла — 35 МиБ. Большие изображения уменьшаются до 4096 пикселей по длинной стороне и 6 Мп с уведомлением. Фотографии остаются в памяти документа. Для загрузки приложения нужен доступ к GitHub Pages. Работа в Telegram открывается обычной ссылкой; меню Main Mini App можно подключить после проверки.

Проверка из корня проекта: `python tools/check_privacy_workshop.py` (установленные Python Playwright, Pillow и Chrome). Результаты и снимки находятся в `output/workshop-check/`.
