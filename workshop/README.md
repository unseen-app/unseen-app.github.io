# Мастерская приватности Unseen · бета 0.5

Страница `/workshop/`. Вход доступен из навигации сайта и отдельного блока под главным экраном. Настройки бота не меняются.

Статический HTML, CSS и JavaScript без аналитики, загрузки пользовательских файлов на сервер и хранения содержимого файлов. Все декодеры размещены локально в `vendor/` с фиксированными версиями и контрольными суммами в `vendor/import-libraries.json`. CSP допускает загрузку ресурсов только с того же сайта. `unsafe-inline` и JavaScript `unsafe-eval` запрещены; `wasm-unsafe-eval` нужен только для компиляции доверенных декодеров WebAssembly. Пользовательский код не запускается.

Поддерживаются непрозрачные маски, пикселизация, перемещение и изменение размера областей, отмена, сравнение, квадратный кадр, свободная обрезка и повороты на 90°. Маски остаются в координатах исходного растра и сохраняются при обрезке и поворотах.

## Форматы и безопасный импорт

- Изображения: JPEG/JFIF/JPE, PNG, WebP, GIF, BMP, AVIF, HEIC/HEIF, TIFF. GIF и TIFF открываются первым кадром/изображением.
- PDF: выбор страниц, отдельные маски для каждой страницы. JavaScript, активные действия, вложенные файлы и шифрование не принимаются. Сценарии и интерактивные слои не запускаются.
- DOCX, XLSX, PPTX, ODT, ODS, ODP: только текстовый предпросмотр. Таблицы показывают сохранённые значения без вычисления формул, презентации — текст слайдов. Изображения, диаграммы и исходная вёрстка не воспроизводятся. Для точной вёрстки нужен PDF.
- TXT/CSV: UTF-8 или UTF-16, только отображение текста. Бинарные данные и явные скриптовые/HTML-заголовки отклоняются.
- SVG/HTML, скрипты, исполняемые файлы, обычные архивы, старые DOC/XLS/PPT, файлы с паролем и офисными макросами запрещены. Неподдерживаемые форматы отклоняются без попыток универсального открытия.

В `file-guard.mjs` проверяются имя, двойное исполняемое расширение, размер, сигнатура и структура контейнера. Содержимое должно соответствовать расширению. Для ZIP-контейнеров проверяются каталог, локальные заголовки, пересечения, шифрование, пути, размеры и коэффициент распаковки. Разрешённые XML-части распаковываются в отдельном завершаемом worker с фиксированными буферами и проверкой CRC. DTD/ENTITY, макросы, активные части и внешние ресурсы отклоняются. Гиперссылки остаются инертным текстом.

HEIC/AVIF/TIFF декодируются отдельным worker с лимитом времени, ресурсной политикой ImageMagick и ограниченным списком кодеров. Делегаты, фильтры, косвенные пути, активные и псевдоформаты запрещены. PDF использует PDF.js с worker, отключёнными eval/XFA и ограничениями страниц, времени и сложности. Результат отображается только в Canvas. Содержимое документов не вставляется в HTML.

Проверка структуры не является антивирусным заключением. Допустимый контейнер может содержать скрытые произвольные байты, а в декодерах возможны ещё неизвестные ошибки. Оригиналы не публикуются и не пересылаются. Экспорт формирует новый растр вместо копирования исходных данных.

Повторяющийся диагональный водяной знак содержит пользовательскую подпись и необязательную дату с регулируемой прозрачностью. Он наносится на итоговый растр. Есть уменьшение по длинной стороне с сохранением пропорций, собственный размер и качество JPEG 40–100%. Изображения не увеличиваются сверх рабочего размера. После сохранения отображаются размеры и вес файла.

Кнопка «Выбрать кадр» входит в режим обрезки, а «Обрезать» применяет выбранный фрагмент. Выбранный кадр также применяется при сохранении или переходе к «Закрыть»/«Пиксели». При пустом выделении сохранение экспортирует прежний кадр. «Отмена», Escape, отмена последнего действия и сброс в режиме обрезки отменяют только незавершённый выбор. Применённую обрезку можно отменить обычной отменой действия. Разрыв сенсорного жеста не блокирует редактор.

Экспорт PNG/JPEG повторно кодирует растр без исходных EXIF и текстовых метаданных. Экспорт PDF создаёт одностраничный PDF из нового JPEG-растра без исходных объектов, текста, сценариев и вложений. Сохраняется только текущая страница. Для чувствительного текста следует использовать непрозрачную маску. Пикселизация — визуальный эффект, который может оставлять содержание узнаваемым.

Лимит входного файла — 35 МиБ, изображения — 40 Мп и 20 000 px по стороне. Рабочий растр уменьшается до 4096 px и 6 Мп. Максимум 50 страниц предпросмотра и 200 000 символов текста. ZIP: 1500 записей, 64 МиБ суммарной распаковки, 16 МиБ на запись, XML — 2 МиБ на часть/12 МиБ суммарно. Декодирование и распаковка имеют отдельные таймеры. Файлы остаются в памяти документа. Для загрузки приложения и декодеров нужен доступ к GitHub Pages; декодеры редких форматов загружаются по необходимости.

## Запуск из Telegram

Кнопка «Открыть мастерскую» в существующем закреплённом посте канала `@Unseenfree` ведёт на обычную HTTPS-страницу `https://unseen-app.github.io/workshop/?v=6`. Открытие происходит как у обычного сайта, с учётом настроек браузера пользователя. Ссылки `startapp` и кнопка `web_app` в меню бота больше не используются.

Telegram SDK и адаптер Mini App не подключаются. Кнопка сохранения находится на самой странице. Обработка и экспорт остаются локальными; файлы не передаются боту или серверу. Настройку Main Mini App в профиле бота можно отключить только в BotFather — изменение ссылок канала само по себе эту настройку не отменяет.

Проверка из корня проекта: `python tools/check_privacy_workshop.py` (установленные Python Playwright, Pillow и Chrome). Проверяется экспорт, отсутствие внешних запросов, обработка без сети, сохранение масок при всех поворотах и обрезке, водяной знак, сжатие и сенсорное управление. Результаты и снимки находятся в `output/workshop-check/`.

Проверка обычного браузерного запуска, в том числе с оставшимися параметрами Telegram в адресе: `python tools/check_workshop_browser.py`. Проверяется, что SDK не загружается, обычная кнопка сохранения видна и экспортируется PNG/JPEG/PDF без GPS/EXIF и текстовых метаданных исходника. Это проверка в Chrome, а не доказательство поддержки скачивания каждым встроенным браузером.

Форматы и отрицательные проверки: `python tools/check_workshop_imports.py`. Используются безвредные имитации подменённых файлов, макросов, некорректных архивов, PDF с тестовым JS/вложением и шифрованием. Результаты — `output/workshop-import-check/`. Проверка зависимостей: PDF.js 6.5.438, magick-wasm 0.0.46, fflate 0.8.3; npm audit 4 ноября 2026 года — 0 известных уязвимостей. Это снимок базы advisories на дату проверки, не гарантия отсутствия ошибок.
